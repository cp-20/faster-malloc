    Select Scrambled reuse, run to the burst, then switch modes and replay the same seed. A mode change keeps the last result from each mode.

    Model notes: up to 512 B, classes round to 16 B; the ladder then widens from 32 B to 1,024 B steps through 32 KiB. Class 0 handles zero-byte requests, giving 129 class indices. Local limits are max(4, min(256, floor(65,536 / class size))). The counter tracks frees since refill/flush, not list length. Grouping models the experiment’s full-list mechanism, without its bounded-walk tuning. Two-thread trim is coordinated here: both threads flush their locals and stashes; native malloc_trim can only flush the calling thread’s locals. Browser speed is illustrative.

    03 / Locality experiment · ADR 0014 + 0021

    Grouping works. Does it pay?

    Distinct 4 KiB pages touched per 4,096-block burst from a scrambled 32,768 × 64 B pool.

    RecyclingPages / burst
    Free-order512.9
    Grouped at flush (round 2)67.8
    Grouped at refill (round 4)67.7
    Theoretical floor64

    Twice now, grouping has done exactly what it claims — and twice the walk it costs beat the locality it buys on timed workloads (round 4: batch/hold +35 %). v2 keeps free-order recycling; this scenario stays as the instrument for repricing the trade on other hardware.

    Source: docs/adr/0014-free-list-shaping.md (round 2) and docs/adr/0021-refill-side-regrouping-rejected.md (round 4). This measured pool and burst are 16× larger than the interactive example; the page counts should not match.

    06 / Automatic span return · ADR 0020 · round 4

    The peak comes back on its own

    A ~130 MB working set is built and freed, then the process stays lightly active. Drag the slider and watch resident memory over the next half second.

    Source: decay probe, round 4 (working set as in the trim scenario). The ~100 ms pause before v2 lets go is deliberate: a span reallocated inside that window is never unmapped, which is what keeps cyclic workloads at full speed. glibc, without an explicit malloc_trim, returns nothing here at all.
