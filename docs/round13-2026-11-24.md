# Round 13 — 2026-11-24

## Parallel hy4 campaign

Fourteen independent `opencode-go/hy4-flash-free` agents worked in separate
git worktrees.  Each branch was built and measured on GitHub Actions
against its merge-base in the same job (`bench/ci/expbench.py`:
callgrind instruction counts on seven micro workloads plus interleaved
wall-clock/RSS on the real-application fixtures).  The laptop ran only
compiles and the two correctness binaries.

Four mechanisms passed the screen and were combined on
`exp/combined-v2`; fourteen others were rejected with numbers (see
`docs/exp/backlog.md`).  The combined branch at 11 repetitions:

| metric | value |
|---|---|
| micro geomean (Ir) | **0.9612** |
| micro worst | 1.0025 |
| real geomean (ratio of medians) | **0.9845** |
| real paired geomean | **0.9819** |
| real paired worst | 1.005 |
| `sort_p4` | 0.138 -> 0.126 s (paired 0.905) |
| `jq_large` | +0.7% (within noise) |
| peak RSS | flat except `sort` 42 -> 45 MiB |

The accepted changes are ADR 0079 (full per-class local byte budget),
ADR 0080 (geometric realloc headroom), ADR 0081 (adaptive warm large-cache
budget) and ADR 0082 (4 MiB large slab).

v2 is the fastest allocator on five of seven applications (g++ compile,
jq, Python, xz and sort).  It is 0.5% behind jemalloc/tcmalloc on sqlite
(inside the sample ranges) and 1 ms behind glibc on the 17 ms git
revlist process.  Peak RSS: v2 is flat against the previous build except
`sort` (45.7 MiB vs glibc 32.9 MiB), where the realloc headroom is held
until the merge buffers are released.

## Correctness

Every screened branch ran `test_basic`, `bench/stress` under v2 and JIT,
`mtrepeat` (N=5) and a valgrind memcheck of `bench/stress` in CI.
`bench/abicheck.sh` reports `cxxcheck FAIL 1` on `ubuntu-latest` even on
clean `main`; it passes locally with g++ 13 and is left advisory until
the runner-toolchain difference is diagnosed.

## Reproduction

```
# one experiment branch
gh workflow run exp-bench.yml --ref <branch> -f reps=11 \
  -f apps=jq_large,python_data,sort_p4,gxx_compile,git_revlist,sqlite_oltp,xz_mt2

# full allocator matrix
gh workflow run exp-matrix.yml --ref <branch> -f reps=7
```
