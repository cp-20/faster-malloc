# Round 8 — 2026-11-13

## Timer lifecycle

ADR [0040](adr/0040-idle-timer-lifecycle.md) defines the v2/JIT lifetime:
ELF NODELETE refuses physical unload. `dlclose` succeeds but retains code,
TLS callbacks, allocator state and any idle worker until process termination.
Repeated reopen/close reuses that state. Custom builds must retain the linker
flag. No loader-lock destructor join or cancellation is introduced. Normal
exit leaves reclamation to the OS; `pthread_exit` of the final application
thread does not terminate an enabled detached worker. The timer stays off by
default in every profile.

Fork children remain timer-disabled until exec. No implicit post-fork thread
creation or new public restart API is justified; exec is the deliberate safe
lifecycle point. Atfork failure keeps the timer permanently off; create
failure restores the mask, destroys attributes and permits later retry.
Compile-time fault injection is restricted to these timer paths.

Added `bench/idlelifecycle.sh` to the established `bench/round7.sh` suite:
ELF flag checks; twelve late-load/close cycles with worker off/on; pending
application-thread TLS callbacks after close; retained mapping and bounded
task counts; three seconds of post-close worker execution; normal process
exit with active worker; both implementations under permanent atfork/create
failures and transient create failure. The harness explicitly reserves static
TLS for late loading. Atfork-failure tests do not claim multithreaded fork
quiescence without registered handlers.

Validation: `make -j4` and the full `bash bench/round7.sh` pass, including
basic/all profiles, stress ×3 per implementation, check, mt local/cross-free,
realloccache off/on, idlefork off/on, both opt-ins with minimum purge pages,
early-init, TLS-exit, and the added lifecycle/fault matrix. Separately, both
FM_DEBUG v2 and JIT stress pass with `FM_RELEASE_AGE_MS=0`,
`FM_PURGE_MIN_PAGES=1`, `FM_IDLE_RELEASE=1`. `git diff --check` passes.
No performance/default-promotion claim is made; measurements belong to the
separate Measurements section.
